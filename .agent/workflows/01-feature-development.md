# Workflow: Feature Development

When implementing a new feature:

1. Understand the existing folder structure.
2. Identify the correct module for the feature.
3. Avoid placing everything in one script.
4. Add reusable functions/classes.
5. Add CLI arguments if the feature is a script.
6. Validate inputs and paths.
7. Save outputs in the expected project folders.
8. Run the related command after implementation.
9. Report:
   - files created
   - files modified
   - commands run
   - output summary
   - warnings or errors
   - next recommended step

Do not make unrelated changes.
